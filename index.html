Осмотрите последовательные срезы → поставьте метку → запишите наблюдение и неопределённость → добавьте нужные снимки → сохраните ZIP.

Точки и русские заметки автоматически сохраняются в этом браузере. Общие данные MICrONS не меняются. Резервную копию храните в ZIP.

Что сохраняется и как восстановить работу
  • Сохранить все результаты — все записи без изображений.
  • Текущие виды — все записи и только текущие 2D / 3D; текущий Neuroglancer добавляется, если он уже открыт для этого случая. Сохранить случай — записи этого случая и текущие 2D / 3D.
  • Все сохранённые снимки — полная копия со всеми добавленными или восстановленными снимками и их связями с метками. Копия случая охватывает все его объёмы. Также добавляются текущие 2D / 3D, если они готовы. Ранее сохранённые изображения из старых версий включаются для сохранности.
  • Откройте ZIP кнопкой «Загрузить сохранённые результаты» без распаковки: восстановятся записи и включённые снимки. «Загрузить случай» принимает файл одного случая. Внутри ZIP: CSV — для Excel, PNG — изображения, JSON — данные для восстановления.

Заданные контакты

Не проверены

Точки задают начало поиска. Для оценки синапса и непрерывности мембраны просмотрите соседние срезы.

В 2D метки видны на своих срезах. В 3D видны все включённые точки. Выбор точки не меняет видимость остальных.

Метки выключены по умолчанию.

Система координатЛокальные XYZ = floor(нм XYZ / размер вокселя XYZ) − начало объёма XYZ

Индексы начинаются с нуля. Страница TIFF = локальный Z + 1. Верхняя граница объёма не включается. Точка показывается только на своём срезе, без проекции на соседние.

X направлен вправо, Y — вниз. Координаты курсора в нанометрах относятся к началу вокселя (минимальным XYZ). Поправка на регистрацию не применяется.

Заключение и покрытие этого случая

«Нет дополнительных контактов» требует полного осмотра головки и шейки с разрешёнными границами. Сохраняйте неопределённость. Рамка TIFF сама по себе не является границей исследуемой структуры.

Сохранённые снимки

Добавляйте только нужные виды: просмотр сам по себе не создаёт снимки. Снимок связывается с выбранной меткой, если она есть. Новые снимки не заменяют прежние. Для резервной копии выберите «Все сохранённые снимки» в панели сохранения.

Neuroglancer

Вернуться к 2D / 3D

Выберите случай в основном просмотрщике.

Открыть в отдельном окне ↗
В 2D видны метки на текущем срезе. В 3D — на всех глубинах.
«Сохранить случай» — текущие 2D / 3D. «Все результаты + текущие виды» также включает текущий вид Neuroglancer с метками.

При включённом флажке открытые вкладки и окна синхронизируются в этом браузере: случай, срез, положение, масштаб, видимость объектов и меток. Нажатие на точку показывает её в остальных видах. Выбор строки в списке отметок открывает свойства; «Перейти к метке» перемещает изображение. Изменения яркости, прозрачности и соседних структур также передаются при включённой синхронизации. При повторном включении Neuroglancer переходит к текущему виду 2D / 3D. Создавайте и редактируйте исследовательские метки в основном просмотрщике или окне заметок. Интерфейс Neuroglancer — на английском.

Ваши точки и русские заметки передаются в личный слой Neuroglancer. Они не публикуются в общей базе аннотаций и не изменяют MICrONS. Отметки и текст могут входить в сохранённый ZIP и переданную вами ссылку Neuroglancer. Навигация и настройки вида синхронизируются, пока включён флажок. Изменение самих аннотаций инструментами Neuroglancer не записывается в результаты исследования; используйте панель отметок.
